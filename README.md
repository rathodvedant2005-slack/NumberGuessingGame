                                               Number Guessing Game (Java)
----- About the Task
The Number Guessing Game is a simple console-based Java application where the computer selects a random number, and the player tries to guess it within a limited number of attempts. The game offers three difficulty levels and provides hints to help the player guess the correct number.
____Features
•	Three difficulty levels: Easy, Medium, and Hard.
•	 Random number generation.
•	 Hints such as "Too high" and "Too low".
•	 Additional hints based on how close the guess is.
•	 Tracks games played, games won, and win percentage.
•	 Records the best score based on the fewest attempts.
•	 Option to play multiple rounds.
____Technologies Used
•	Java
•	Java Random class
•	Scanner class
•	Conditional statements (if-else)
•	Loops (while)
•	Variables and data types
•	Mathematical operations
____Requirements
•	Java JDK installed on your computer.
•	Any Java IDE, such as IntelliJ IDEA, Eclipse, or Visual Studio Code.

-------How to Run the Project
Step 1: Open the Project
Open the project folder in your preferred Java IDE or terminal.
Step 2: Compile the Program
javac NumberGuessingGame.java
Step 3: Run the Program
java NumberGuessingGame
-------- How to Play
1.	Run the program.
2.	Choose a difficulty level:
o	Easy: Numbers from 1 to 50, with 10 attempts.
o	Medium: Numbers from 1 to 100, with 7 attempts.
o	Hard: Numbers from 1 to 200, with 8 attempts.
3.	Enter your guess.
4.	Follow the hints provided by the computer.
5.	Try to guess the correct number before running out of attempts.
6.	View your game statistics.
7.	Choose whether to play again.
